# Design council

Debates turn open design questions into written proposals for David. They never ship changes by themselves.

## Panel

| Agent | Argues for |
| --- | --- |
| `designer-engagement` | Return visits, loops, collection, events |
| `designer-competitive` | Fair, skillful, readable races and earned upsets |
| `designer-child-safety` | Roblox policy, ethical monetization, no pressure tactics |
| `designer-young-player` | Clarity, mobile-first UX, what 8–13-year-olds find fun |
| `roblox-researcher` | Facts with primary sources (not a voter) |
| `design-moderator` | Runs the protocol, writes the record (not a voter) |

## Protocol

1. **Frame**: one-sentence question, constraints (CLAUDE.md hard rules, `Accepted` decisions).
2. **Facts**: researcher brief, sources linked.
3. **Openings**: each designer, independently, ≤ 250 words.
4. **Rebuttals**: each designer responds to the others and says what would change their mind.
5. **Synthesis**: options table, agreements, splits, one recommendation, minority view kept.
6. **Hand-off**: scribe logs a `Proposed` decision and an open question for David.
